# 求职助手（hiremate）

面向 **`WorkBuddy`** 与 **`DeepSeek Harness (dsh)`** 用户的求职自动化插件：**帮你深筛排外包、管好四态投递账本，并在你授权的边界内像真人一样跟进 HR 消息与投递多版本简历。**

> 隐私说明：你的 PDF 简历原件、真实联系方式、个人求职档案与本地投递账本始终存储在你自己的电脑上（默认 `~/.hiremate/`）；使用 Pro 云端深筛或话术守卫时仅对当前单条岗位/消息文本做实时评估，云端不做留存。

---

## 为什么做这个插件？

普通的“自动海投脚本”只会无脑点打招呼：既容易误投驻场外包甚至投回前东家社死，又没法承接建联后最耗心神的 **HR 追问经历、索要对应方向简历、推进约面**。

**求职助手** 把一套真实社招跑通的完整方法做成了原生 Agent 插件：

1. **5 分钟对话建档 + 前东家自动拉黑**：把简历丢进对话即可提炼《个人求职事实与答法档案》，自动识别过往任职企业同字号归一化加入屏蔽名单。
2. **半自动 / 全自动双环节自由切换**：「主动找岗破冰」和「消息答疑发简历」可分别设为半自动（出审阅单，回复序号再发）或全自动（工作时段定额托管）。
3. **四态精细拆账 + 三维查重 + 桌面弹窗提醒**：严格区分 `开场已送达`、`双方已建联`、`已发简历请求（待同意）`、`PDF 简历已送达` 与 `待本人约面/决策`（触发约面/谈薪/超纲时自动弹出本机系统通知）；结合本地账本与网页历史会话防换 HR 重复打招呼。
4. **免验证码一键浏览器设备配对**：运行 `auth login` 自动拉起浏览器确认设备（支持邮箱一键魔法确认链接及已启用的社交账号快捷登录），告别在聊天框里手敲数字验证码。
5. **只读高密度本地静态看板 + 原生 Excel 导出**：随时一键生成 `dashboard.html` 查看求职转化漏斗、招聘者职务头衔、匹配依据与缺口，支持零依赖导出带冻结表头的原生 Excel（`.xlsx`）与 UTF-8 BOM CSV。

## 30 秒安装方式

环境要求：本机已安装 Python 3.9+（macOS 自带 Python 即可运行，推荐 3.11/3.12），且正在使用 `WorkBuddy` 或 `DeepSeek Harness`（同时兼容自动发现 `~/.agents`、`~/.claude`、`~/.codex`）。

### 方式一：直接让桌面 Agent 替你安装（推荐，免敲命令）

把下面这句话直接粘贴发给你的 `WorkBuddy` 或 `DeepSeek Harness`：

```text
帮我安装并启动「求职助手」插件：https://github.com/ryunana/hiremate
```

Agent 读取仓库内的 `AGENTS.md` 后会自动运行安装器，并引导你把简历拖进对话完成 5 分钟建档（产品官网与 Pro 账户中心：<https://hiremate.chengway.wang>）。

### 方式二：终端手动一键软链安装

```bash
git clone https://github.com/ryunana/hiremate.git hiremate-open
cd hiremate-open

# 自动安装唯一主副本至 ~/.hiremate/skill/hiremate，并建立目录软链同步到本机全部已安装的 Agent 宿主
python3 install_plugin.py
```

重启宿主客户端后，直接对助手说（或在 DSH 中输入 `/hiremate-status`、`/hiremate-login`、`/hiremate-dashboard`）：

- **「帮我初始化求职助手，这是我的简历：`<简历路径>`」**
- **「帮我在 BOSS 搜索一轮匹配的岗位预览」**
- **「帮我登录求职助手并打开浏览器配对页」**（免输验证码一键绑定账户，在线开通 Pro 秒级直充生效）
- **「把主动找岗设为半自动，消息回复设为全自动」**
- **「我不排斥外包和 OD 机会，但不接受驻场，帮我更新筛选偏好」**（外包/派遣与驻场均可独立设为排除、仅接被动来信或完全开放）
- **「刷新并打开我的求职看板」**
