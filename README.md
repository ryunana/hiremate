# 求职助手 HireMate

**简历给我，你去忙，该面试了再叫你。**

适配 **Codex · WorkBuddy · DeepSeek Harness (dsh) · Claude Code · Cursor** 等主流桌面 Agent 的开源求职自动化插件。自动完成**职位深筛、外包排雷、HR 消息答疑与多版本简历投递**——常规沟通交由系统推进，关键节点交还本人确认。

无需敲命令行，把下面整句话直接发送给电脑上的 `WorkBuddy`、`Codex`、`DeepSeek Harness`、`Claude Code` 或 `Cursor` 即可：

## 为什么做这个插件？

普通的“自动海投脚本”只会无脑批量打招呼：既容易撞上换壳的驻场外包、甚至误投回前东家当场社死，也承接不了建联之后最耗心力的 **HR 追问项目细节、索要对口方向简历、推进约面**。

**求职助手（HireMate）** 把一套真实社招验证过的完整方法做成了原生桌面 Agent 插件，用 **6 件事**替你接管找工作里的重复体力活：

1. **个人履历，一键建档** —— 拖入本地 PDF 简历（或直接读取 BOSS 直聘在线简历），5 分钟提炼《个人求职事实与答法档案》；**自动识别全部过往雇主及同字号关联主体加入拉黑名单**，并在落盘前完整摊开 **8 项筛选策略**供你透明确认，绝不暗箱套用默认规则。
2. **匹配好岗，排雷精选** —— 穿透职位描述（JD）与公司主页识别伪装外包、劳务派遣与驻场外派（外包/OD、驻场、猎头渠道均可独立设置「全部过滤 / 仅接被动来信 / 完全开放」）；结合本地台账与网页会话**三维查重**，防止同企业换 HR 重复打扰。
3. **多版简历，对口直投** —— 支持绑定多份不同侧重点的线上附件简历（如 AI 产品方向 / B 端 SaaS 方向），按目标岗位重心自动匹配对应版本精准发送（Pro）。
4. **HR 追问，真人代回** —— 严格依据你的真实履历拟定简短自然的口语回复，去 AI 客服腔、未涉及的经历如实说明绝不虚构；支持**半自动审阅确认（免费）**与**工作日错峰全自动托管（Pro）**按需独立切换。
5. **聊到约面，弹窗叫你** —— 一旦对话涉及**面试时间确认、交换微信或电话、薪资谈判**及超出简历范围的提问，立即暂停自动回复并弹出本机系统通知，把拍板权 100% 留给你本人。
6. **求职进度，一屏看清** —— 内置本地 SQLite 精细状态台账（严格区分 `开场已送达`、`双方已建联`、`已发简历请求`、`PDF 简历已送达`、`待本人约面/决策`、`已约面/跟进中`），随时一键生成高密度本地静态看板 `dashboard.html`，零依赖导出带冻结表头的原生 Excel（`.xlsx`）与 CSV。

## 安全、隐私与防风控机制

| 守护维度 | 具体落地机制 |
| :--- | :--- |
| **个人数据 100% 仅存本机** | PDF 简历原件、真实联系方式、过往雇主黑名单、个人求职档案与本地投递台账全程保存在你自己的电脑上（默认 `~/.hiremate/`）。免费版零云端请求；Pro 云端深筛与话术守卫仅对当前单条岗位/消息文本做实时评估，不做个人数据留存（仅当企业公开简介/JD 命中客观外包派遣特征时脱敏匿名去重计票，反哺公共排雷池）。 |
| **有头持久化浏览器 · 零爬虫** | **严禁使用 Headless 无头浏览器或任何 `curl`/`requests` 爬虫脚本抓取网页**。全程复用本机已登录的有头持久化浏览器窗口：自动检测宿主自带 `Browser Use` 能力——不支持有头持久化时直接启用防风控且省 Token 的 [`ego lite`](https://lite.ego.app/)；支持时由你按 Token 充裕度自由二选一。Pro 自动巡检仅在工作日白天错峰低频运行，夜间自动休眠，遇到滑块或安全验证立即原样停手交由本人处理。 |
| **无浏览器权限也能丝滑使用** | 若当前环境未开启浏览器操控或不便安装软件，自动无缝切换为**副驾驶粘贴模式（`copilot`）**——直接把岗位 JD 或 HR 消息贴进对话框，同样可执行排雷评估、生成真人短句草稿并计入本地台账。 |

## 安装与日常使用指南

### 环境与宿主支持

- **运行环境**：macOS / Windows / Linux，本机已安装 **Python 3.9+**（macOS 自带 Python 开箱即用，推荐 3.11+；纯标准库实现，**零第三方 `pip` 依赖**）。
- **自动发现与软链同步宿主**：`WorkBuddy`、`DeepSeek Harness (dsh)`、`Codex`、`Claude Code`、`Cursor`、`Windsurf`、`Antigravity` 及通用 `~/.agents` 目录（一次安装升级，本机多端自动同步生效；`dsh` 额外自动挂载 `/hiremate-status`、`/hiremate-login`、`/hiremate-dashboard`、`/hiremate-update` 原生斜杠命令）。
- **招聘平台**：当前版本支持 **BOSS 直聘**，更多招聘平台将在后续版本逐步适配。

### 终端手动安装与无损卸载（开发者可选）

除了直接把仓库地址发给桌面 AI 自动安装外，你也可以在终端手动执行：

```bash
git clone https://github.com/ryunana/hiremate.git hiremate-open
cd hiremate-open

# 写入唯一主副本至 ~/.hiremate/skill/hiremate，并自动软链至本机全部已安装的 Agent 宿主
python3 install_plugin.py

# 如需卸载插件软链与运行文件（默认 100% 保留 ~/.hiremate 下的本地求职档案与台账）
python3 install_plugin.py --uninstall
```

### 装好后直接对桌面 AI 说这些话

无需记忆复杂命令，日常在聊天框用自然语言吩咐即可：

- **建档起步**：「帮我初始化求职助手，这是我的简历：`<拖入简历文件>`」（没导出 PDF 也可说：「直接读取我的 BOSS 直聘在线简历帮我建档」）
- **首轮试跑**：「帮我在 BOSS 搜索一轮匹配的岗位预览」（免费版先出排雷结果与破冰审阅单，未经你点头绝不发送）
- **微调偏好**：「我不排斥外包和 OD 机会，但不接受驻场，帮我更新筛选偏好」
- **激活与全托管（Pro）**：「帮我登录求职助手并打开浏览器配对页」/「把主动找岗设为半自动，未读消息回复设为全自动，并开启工作日错峰巡检」
- **复盘与导出**：「刷新并打开我的求职看板」/「把我的投递台账导出成 Excel 表格」
- **一键无损升级**：「升级求职助手」（每 6 小时静默感知新版本并在对话/看板提醒，支持带自动备份回滚的热更新，100% 保留本地简历档案、台账与 Pro 设备凭证）

## 常见问题（FAQ）

<details>
<summary><b>1. 手头没有导出 PDF 简历文件，可以直接开始用吗？</b></summary>
<br/>
可以。只要你已经在 BOSS 直聘填好了「在线简历」，开启浏览器权限后直接让桌面 AI 读取在线简历全文即可完成建档与前东家自动屏蔽；同时建议顺手点一下在线简历右上角的「生成附件简历」，方便后续向 HR 发送附件。
</details>

<details>
<summary><b>2. 会不会胡乱编造项目经历，或者替我乱答应面试时间和薪资？</b></summary>
<br/>
不会。系统严格基于你确认落盘的《个人求职事实与答法档案》作答，简历未提及的技术栈或经历会如实坦诚说明；一旦识别到具体约面时间、索要微信/手机号、谈薪压价或超纲问题，会立即暂停自动回复并触发桌面系统弹窗提醒你本人接手。
</details>

<details>
<summary><b>3. Pro 全托管版怎么激活？换电脑后还能继续用吗？</b></summary>
<br/>
采用<b>一次买断制（¥69）</b>，无后续按月订阅费用。通过邮箱免密登录完成支付（或使用兑换码核销）后，权益永久绑定你的个人账户；在桌面端对 AI 说「帮我登录求职助手」即可拉起浏览器一键配对启用。单账户支持本人最多 <b>2 台电脑</b>同时在线，换机时可在<a href="https://hiremate.chengway.wang/activate">账户中心</a>随时自助解绑旧设备。
</details>

<details>
<summary><b>4. 后续插件发布新版本怎么升级？本地简历和投递记录会丢吗？</b></summary>
<br/>
不会丢失。插件每 6 小时静默检查一次新版本并在对话或看板顶部温和提醒；只需对桌面 AI 说一句<b>「升级求职助手」</b>（或运行 <code>python3 hiremate.py update</code>），即可自动完成热更新与多宿主软链同步，全程带快照回滚保护，100% 保留 <code>~/.hiremate/</code> 下的个人档案、投递台账与登录凭证。
</details>
